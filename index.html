🎓 Sobre o Projeto FrontLingo (UTFPR)

Este projeto foi concebido na disciplina AS64C - Certificadora de Competência Comum da Universidade Tecnológica Federal do Paraná (UTFPR).

Objetivo Geral: Desenvolver um Recurso Educacional Aberto (REA) interativo para o ensino de conceitos fundamentais de Front-End, utilizando metodologias ativas de gamificação e microlearning inspiradas no Duolingo e no Mimo, resultando na construção autônoma de um Currículo Web profissional publicado no GitHub Pages.

✏️ Personalizar Meu Currículo

🚀 Publicando no GitHub Pages

Com o GitHub Pages, seu currículo ficará disponível para qualquer recrutador no mundo com uma URL gratuita e rápida!

1
Baixe seu arquivo index.html

Clique no botão verde "Baixar index.html Pronto" para exportar seu código completo.

2
Crie um Repositório no GitHub

Acesse github.com/new, dê um nome como meu-curriculo-web e marque como Public.

3
Faça o Upload do index.html

Arraste o arquivo index.html para dentro do repositório e confirme em Commit changes.

4
Ative o GitHub Pages

Vá em Settings > Pages. Em Branch selecione main e clique em Save. Em 1 minuto seu site estará no ar!
